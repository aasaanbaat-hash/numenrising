# IMMERSIV - India's First International Floating Breathwork Experience

A premium landing page for IMMERSIV, brought to you by Numen Rising. Experience floating breathwork at select ITC Hotels across India.

## Features

- **Responsive Design**: Pixel-perfect across desktop, tablet, and mobile
- **Lead Generation Form**: Integrated form with email backend (Formspree)
- **Premium Aesthetics**: Luxury brand experience with elegant typography
- **Performance Optimized**: Fast loading with optimized images
- **Accessibility**: Semantic HTML and WCAG compliant

## Deployment

### Netlify (Recommended)
1. Push to GitHub
2. Connect repository to Netlify
3. Netlify automatically deploys on push

### Manual Deployment
1. Extract all files
2. Upload to your hosting provider
3. Ensure all relative paths are preserved
